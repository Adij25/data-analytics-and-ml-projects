# Data Analytics and Machine Learning Projects

This repository contains two end-to-end data projects completed as part of data analytics and machine learning assignments.

The projects demonstrate practical implementation of data cleaning, exploratory data analysis, SQL, business intelligence, machine learning, and MLOps.

## Projects

### Task 1 – E-commerce Sales Analysis

**Folder:** `task1-ecommerce/`

An end-to-end e-commerce data analytics project focused on cleaning raw datasets, identifying sales trends, analyzing business performance, and generating actionable insights.

**Technologies:**
- Python
- Pandas and NumPy
- Jupyter Notebook
- MySQL
- SQL Window Functions
- Microsoft Power BI

**Key Deliverables:**
- Data cleaning and preprocessing.
- Exploratory Data Analysis with visualizations.
- Seven SQL business analysis queries.
- Interactive Power BI dashboard.
- Business insights report in PDF format.

### Task 2 – Customer Churn Prediction (End-to-End MLOps)

**Folder:** `task2-churn/`

A machine learning project that predicts customer churn using customer demographics, service subscriptions, contract information, and billing details.

**Technologies:**
- Python
- Pandas and NumPy
- Scikit-learn and XGBoost
- Optuna
- SHAP
- MLflow
- Evidently
- FastAPI
- React and Vite
- Pytest
- Docker

**Key Deliverables:**
- Exploratory Data Analysis and preprocessing.
- Model comparison and hyperparameter optimization.
- Model evaluation and business-oriented threshold selection.
- SHAP-based model explainability.
- MLflow experiment tracking and model registry.
- Data drift monitoring.
- FastAPI prediction service.
- Interactive React dashboard.
- Automated testing and Docker support.
